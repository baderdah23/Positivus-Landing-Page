# Positivus Landing Page

A beautiful, premium, and fully responsive digital marketing agency landing page. Built with **React**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**.

## 🚀 Features

- **Responsive Design**: Custom optimized layouts for Desktop, iPad, and Mobile screens.
- **Interactive Navigation**: Features a dynamic mobile burger menu with seamless sliding transitions.
- **Dynamic Loops & Carousels**: Continuous logo loop ticker for corporate partners.
- **Detailed Accordions**: Interactive process steps and service description cards.
- **Clean Forms & Alerts**: Beautiful contact form with instant validation/alert states.
- **Rich Typography**: Space Grotesk elegant font integration.

## 🛠️ Tech Stack

- **Framework**: React 19 (Vite build system)
- **Styling**: Tailwind CSS v4 & custom CSS variable design system
- **Icons**: Lucide React
- **Animations**: Framer Motion & tw-animate-css

## 📦 Setup & Installation

1. **Clone the repository and navigate into it**:
   ```bash
   cd landing-page
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Start local development server**:
   ```bash
   npm run dev
   ```
4. **Build for production**:
   ```bash
   npm run build
   ```
